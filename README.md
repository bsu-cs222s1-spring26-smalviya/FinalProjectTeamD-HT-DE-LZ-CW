## How To Run

### USE JAVA 21

### Gradle configurations:
To use this program *AT ALL*, you will need an API key from https://fdc.nal.usda.gov/api-key-signup
Once you sign up and get an API key, you will need to follow the instructions below:
* Go to "C:\Users\{Your-Username-Here}\.gradle"
* Create/open gradle.properties in your .gradle folder
* paste your API key following the gradle.properties.template
* sync the gradle changes in your IDE and see if it runs.
* (The filepath for this new gradle.properties should look like this: "C:\Users\{Your-Username-Here}\.gradle\gradle.properties"

### Running the program
* Go to "src\main\java\Main\" and run the file "main.java"
* If there are any errors, report them below.

* *Log In Screen*
* To log in, type 1 into the console
* sign in with your username and password you set beforehand

* *Sign up Screen*
* To sign up, type 2 into the console
* A unique id will be set to your user and you will be able to log in using your unique username and password
* Once you do that, you will be sent back to the log in screen

* *Main Menu* 
* using 1-3 choose the options below, follow any prompts after, and enjoy our app!
